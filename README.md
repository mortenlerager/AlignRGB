AlignRGB Preview v0.3

Automatic RGB channel alignment for planetary images in PixInsight.

This JavaScript (PJSR) script automatically aligns the red, green, and blue channels to reduce color fringes around planetary edges.

Developed and tested with PixInsight 1.9.5.

Features

Automatic RGB channel alignment

Uses a selected Preview as the alignment region

Particularly useful for planetary images such as Saturn and Jupiter

No manual channel shifting required

Installation

Download AlignRGB_Preview_v03.js.

Open PixInsight.

Select Script → Feature Scripts.

Click Add and select the folder containing the script.

The script will appear under Script → MyScripts → AlignRGB Preview.

Usage

Open an RGB planetary image.

Create a Preview containing the entire planet.

Select the Preview.

Run Script → MyScripts → AlignRGB Preview.
